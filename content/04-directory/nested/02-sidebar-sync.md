# 嵌套子页 B：多级子目录与侧边栏同步机制

在纯 Markdown 母版仓库中，新增一篇子目录文档无需修改任何外部配置文件；派生到 Hugo 后，只要父目录已放置 `_index.md`（Branch Bundle），新建任何 `.md` 子文档并填写 `weight` 即可由模板 `.Pages.ByWeight` 自动挂载进侧边栏，彻底杜绝漏改全局配置文件导致的“孤岛页”。
