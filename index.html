Hugo Extended (0.170.1) 基准实测子站

本子模块由主仓 page2401.github.io/docs/ 标准 GFM 母版最小化派生适配而来，实测 Go 语言生态标杆单二进制生成器 Hugo Extended v0.170.1（内置 Goldmark 解析内核 + Render Hooks 钩子机制 + Page Bundles 目录模型）的真实工程表现。

01. 专属标注与元数据 →

实测 Shortcode {{< callout >}} 与 Goldmark render-blockquote.html 原生直通 GFM Alerts。

02. 流程图与时序图 →

通过 1 行 render-codeblock-mermaid.html 钩子直连本地锁定的 mermaid@12.3.0。

03. 数学公式排版 →

开启 Goldmark passthrough 定界符透传 + render-passthrough.html 零转义损耗接入 katex@0.19.1。

04. 目录结构与路由取舍 →

深度剖析 Hugo 独有的 _index.md（Branch Bundle）与 index.md（Leaf Bundle）吞噬子路由陷阱。

05. 高阶代码块与语法高亮 →

实测内置 Go Chroma 引擎零 JS 静态高亮、{hl_lines=[3,"7-9"], linenos=table} 行号聚焦与 diff 着色。

精确锁定版本档案（ssg-lock.json）

Hugo 作为 Go 静态编译单文件引擎，无需 node_modules 或虚拟环境，全站构建毫秒级完成；前端数学与图表运行时完全本地化托管于 static/vendor/，零外部 CDN 依赖：

模块 / 组件精确锁定版本在本子站中的职责与接入方式
hugo (Extended)0.170.1Go 单二进制核心编译器（内置 SCSS/SASS、Chroma 高亮与 Goldmark AST 钩子）
goldmarkbuiltin内置 CommonMark / GFM 解析器，开启 unsafe = true 与 passthrough 数学透传
chromabuiltinGo 原生词法高亮器，开启 noClasses = false 输出纯静态 .chroma 语义类
katex0.19.1托管于 static/vendor/，配合 render-passthrough.html 精确渲染行内与块级公式
mermaid12.3.0托管于 static/vendor/，配合 render-codeblock-mermaid.html 与 data-theme 联动深浅色绘图
